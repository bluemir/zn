# Spec

## UI 구성

- 좌측 sidebar
	- filetree
- 하단 statusBar
	- mode 표시
	- 2줄로 표시


## Mode

모드는 다음과 같이 구성 한다.

- normal mode
- insert mode
- visual mode

### Normal mode

vim 의 normal mode 와 동일하다.
cursor 를 옯기고, 파일을 편집 한다.

#### key mapping

키 | 기능 | 기타
---|------|-----
a  | 현제 커서 바로 뒤에 insert mode 변경

### insert mode

vim 의 insert mode 와 동일 하다.
현제 커서 위치에 내용을 삽입한다.


## visual mode

vim 의 visual mode 와 동일하다
