# ADR-0157 창 제목의 경로는 연 폴더의 이름부터 적는다

- 상태: 채택
- 날짜: 2026-10-15
- 관련: ADR-0110(터미널 창 제목). 그 ADR 의 3 에 적은 제목 모양을 바꾼다

## 맥락

창 제목은 `zn editor.go (internal/core)` 였다. 괄호 안은 편집기를 띄운 자리(cwd) 기준 상대 경로라, 저장소를 여럿 창마다 띄워 두면 어느 창이 어느 저장소인지 제목으로 갈리지 않았다. `zn main.go` 가 창마다 하나씩 서는 꼴이다.

정할 것은 둘이다.

1. 연 폴더를 얼마나 적는가
2. 파일 이름과 폴더를 어떤 차례로 적는가

## 1. 연 폴더는 끝 이름 하나다

`~/src/bluemir/zn` 에서 띄우면 `zn` 만 적는다. 홈부터 다 적으면 앞쪽 `~/src/bluemir/` 이 창마다 같아서, 창을 갈라 주는 부분이 뒤로 밀리고 창 목록과 tmux 상태줄이 뒤를 자를 때 먼저 잘린다(ADR-0110 이 `zn` 을 앞에 둔 것과 같은 까닭이다).

같은 저장소를 두 벌 받아 두면 끝 이름이 같아 갈리지 않는다. 그것은 폴더 이름을 다르게 두는 것으로 푼다.

## 2. 폴더 이름부터 한 경로로 적는다

```
zn zn/internal/core/editor.go +
```

괄호로 나누던 것을 경로 하나로 합친다. 「어느 저장소의 어느 파일」이 왼쪽에서 오른쪽으로 읽힌다. `+` 는 그대로 끝이다.

- **연 폴더 밖의 파일**(정의를 따라 나간 module cache) 은 앞에 연 폴더를 붙이지 않는다. 그 폴더 아래가 아니라서다. 홈을 `~` 로 줄인 경로를 그대로 적는다(`shortenPath`)
- **이름이 없는 buffer** 는 `zn/[No Name]` 이다. 저장하면 연 폴더 아래에 생긴다
- **볼 파일이 없으면** `zn zn` 이다. 그래도 어느 창인지는 갈린다

## 기각한 것

- **파일 이름을 앞에, 경로를 괄호에**(`zn editor.go (zn/internal/core)`). 파일 이름이 먼저 서는 것은 좋지만 저장소가 괄호 끝으로 가서 잘릴 때 먼저 사라진다. 창을 가르려는 것이 이 일의 목적이다
- **연 폴더를 홈부터 다 적기.** 1 에 적었다

## 결과

- 제목이 길어졌다. 깊은 파일은 tmux 상태줄에서 뒤가 잘린다. 잘려도 `zn 저장소/` 는 남는다
- 상대 경로로 연 파일도 cwd 를 붙여 견주므로 같은 모양이 된다
