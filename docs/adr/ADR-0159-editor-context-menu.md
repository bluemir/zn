# ADR-0159 편집 영역 우클릭이 컨텍스트 메뉴를 띄운다

- 상태: 채택
- 날짜: 2026-10-21
- 관련: ADR-0146(트리 우클릭 메뉴), ADR-0110(겹쳐 그리는 화면은 부모의 view 를 쓴다), ADR-0051(언어 서버), ADR-0068(사용처로 가기), ADR-0067(이름 바꾸기 창), ADR-0148(OSC 52 시스템 클립보드)

## 맥락

트리는 이미 우클릭으로 파일·디렉터리 조작 메뉴가 떴다(ADR-0146). 반면 편집 영역 본문(`regionText`) 은 오른쪽 버튼을 눌러도 아무 일도 일어나지 않았다.

`docs/tasks.md` 에 「변수나 함수의 우클릭 기능 (정의로 가기, 사용하는 곳으로 가기 등.)」이 열려 있었다. 키맵(`\gd`, `\gr`, `\rn`, `*`) 을 아직 외우지 않은 사용자나, 마우스로 코드를 둘러보던 중에 심볼의 정의나 사용처를 곧바로 찾고 싶을 때 마우스로 들어가는 문이 필요했다.

정할 것은 넷이다. **우클릭했을 때 커서를 어디로 옮기는가**, **부모 모드를 어떻게 유지하는가**, **LSP 가 없거나 단어가 아닐 때 메뉴를 어떻게 그리는가**, **무엇을 항목으로 두는가**다.

## 결정

### 1. 우클릭 좌표로 커서를 옮기고 그 자리에 메뉴를 띄운다

편집 영역(`regionText`) 우클릭은 커서를 누른 자리로 옮긴 뒤(`clickText`) 그 단어/심볼을 대상으로 메뉴 상자를 연다.

- 심볼에 대한 메뉴이므로 커서가 그 심볼에 서야 대상이 성립한다
- 메뉴 상자는 누른 자리 바로 아래에 뜨며, 화면 아래로 넘치면 위로 뒤집힌다(`popupPos`). statusBar 두 줄은 덮지 않는다
- **선택 영역이 있는 Visual 모드는 커서를 옮기지 않는다.** 이미 고른 범위를 깨뜨리지 않고 그 선택 영역 자체를 메뉴의 대상으로 삼는다

### 2. 부모 화면을 들고 `AllMotion` 만 올린다 (ADR-0110, ADR-0146)

트리 메뉴(`viewSidebarMenu`) 와 같은 손이다.

- `parent tea.Model` 을 필드로 들고 `View()` 는 `m.parent.View()` 에 `MouseMode = tea.MouseModeAllMotion` 만 올려 합성한다
- `esc`·`ctrl+c` 나 메뉴 바깥 클릭은 `return m.parent, nil` 로 닫는다. Normal·Insert·Visual 모드가 그대로 보존된다
- 메뉴 항목 중 `단어 검색` 처럼 상태만 바꾸는 것은 실행 후 `m.parent` 로 돌아가고, `정의로 가기` 나 `이름 바꾸기` 처럼 새 화면으로 전이하는 것은 그 화면으로 자연스럽게 넘어간다

### 3. 상자 첫 줄에 대상 이름을 적는다

무엇에 대한 메뉴인지 드러나야 한다.

- 단어 위면 커서 아래의 낱말([`WordUnderCursor`](file:///home/bluemir/src/bluemir/zn/internal/textarea/viewport-search.go)) 을 적는다
- 선택 영역이 있으면 `선택 영역` 이라고 적는다
- 공백이나 빈 줄처럼 단어가 없으면 `편집` 이라고 적는다

### 4. 지원되지 않는 항목은 흐리게(dim) 처리한다

언어 서버가 붙지 않는 파일(Markdown, 텍스트 등) 이나 단어가 없는 자리라고 해서 메뉴가 아예 안 뜨거나 오류 알림만 내지 않는다.

- 심볼이 없거나 언어 서버가 없는 파일에서는 `정의로 가기`, `사용처로 가기`, `이름 바꾸기` 항목을 흐린 글씨(`styleMenuDisabled`, 회색 244) 로 그린다
- 흐리게 처리된 항목은 포인터를 올려도 호버 강조가 붙지 않고, 클릭해도 아무 일도 일어나지 않는다
- 사용자는 이 에디터가 어떤 기능을 지원하는지 시각적으로 인지할 수 있고, 동작할 수 없는 상태임을 명확히 알 수 있다

### 5. 일반 편집 동작도 함께 둔다

- **단어 위**: `정의로 가기`, `사용처로 가기`, `이름 바꾸기`, `단어 검색`(`*`)
- **선택 영역**: `선택 영역 복사`(`actionVisualYank`)
- **공백 또는 일반 상태**: `붙여넣기` (무명 레지스터 또는 시스템 클립보드)

## 결과

- 변수나 함수 위에서 우클릭하여 정의 이동, 사용처 조회, 이름 변경, 단어 검색을 마우스로 실행할 수 있다
- 언어 서버 미지원 파일이나 빈 줄에서도 일관된 맥락 메뉴가 뜨며, 미지원 항목은 비활성(dim) 으로 안내된다
- 메뉴를 닫으면 우클릭 직전의 모드(Normal, Insert, Visual) 로 안전하게 복귀한다
