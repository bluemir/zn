# ADR-0161 toml 강조. 표 머리는 제목 색이고 키는 뒤의 `=` 로 가른다

- 상태: 채택
- 날짜: 2026-10-29
- 관련: ADR-0039(줄 단위 문법 강조), ADR-0040(코드펜스 위임), ADR-0055(json·yaml 강조), ADR-0080(언어는 표의 한 줄), ADR-0160(rust 지원)

## 맥락

rust 를 넣고 나니 같은 저장소의 `Cargo.toml` 이 통째로 흰 글자였다. `pyproject.toml`·`rustfmt.toml` 도 같았다. Cargo 전용이 아니라 toml lexer 하나로 넣는다. 강조만 넣고 언어 서버는 붙이지 않는다.

정할 것은 셋이다.

1. 표 머리(`[package]`) 를 무슨 갈래로 칠하는가
2. 키와 값을 어떻게 가르는가
3. 줄 앞의 `[` 가 표 머리인지 배열인지 어떻게 아는가

## 1. 표 머리는 KindHeading 이다

`[package]`·`[[bin]]` 는 아래 키들을 거느리는 이름이다. 파일을 훑을 때 눈이 짚는 자리라는 점에서 markdown 의 제목과 같은 자리다. 갈래 이름은 그것이 무엇인지로 짓는다(syntax.go 의 Kind). 그래서 언어 이름을 붙인 새 갈래를 만들지 않고 KindHeading 을 쓴다. 새 색도 들지 않는다.

키 색(KindKey) 으로 칠하는 길도 있었다. 그러면 `[dependencies]` 와 그 아래 `serde =` 가 같은 색이 되어 표의 경계가 보이지 않는다.

**머리 전체가 한 토큰이다.** `[target."cfg(unix)".dependencies]` 처럼 점과 따옴표 이름이 섞여도 통째로 제목 색이다. 따옴표 이름 안의 `]` 에서는 닫지 않는다.

## 2. 키는 뒤에 `=` 가 오는 이름이다

키 자리를 문맥으로 세지 않고 **뒤를 본다.** 맨이름(`serde-json`) 이나 따옴표 이름(`"my crate"`) 을 `.` 으로 이은 것 뒤에 `=` 가 오면 키다.

이 한 규칙으로 세 자리가 같이 풀린다.

- 줄 앞의 키(`name = "zn"`)
- 인라인 표 안의 키(`{ version = "1", optional = true }`). `{` 와 `,` 뒤를 따로 셀 일이 없다
- 여러 줄 배열 안의 문자열(`    "editor",`) 은 뒤에 `=` 가 없어서 키가 아니다

값은 따옴표 없는 낱말 하나를 보고 가른다. `true`·`false` 는 KindConstant 이다. 숫자로 시작하거나 `inf`·`nan` 이면 KindNumber 이다. 수·날짜·시각을 한 갈래로 둔다. 날짜도 숫자로 쓴 값이라 갈래를 나눠 얻는 것이 없다.

**문자열은 넷이다.** basic(`"`) 은 `\` 로 escape 하고, literal(`'`) 은 escape 가 없어 `'C:\dir\'` 의 `\` 가 글자다. 세 겹(`"""`·`'''`) 은 줄을 넘는다. 닫는 세 겹 앞에 따옴표가 둘까지 더 붙을 수 있어서(`""""a""""`, TOML 1.0) 세 겹을 만나면 뒤의 따옴표를 둘까지 더 먹는다.

## 3. 열린 괄호의 겹 수를 상태에 든다

줄 앞의 `[` 는 맨 바깥에서는 표 머리이고, 여러 줄 배열 안에서는 안쪽 배열이다.

```toml
matrix = [
    [1, "a"],
]
```

글자로는 같아서 줄을 넘어 열려 있는 `[`·`{` 의 겹 수를 들고 간다(`tomlNormal{depth}`). 겹이 0 일 때 줄 앞의 `[` 만 표 머리다. 세 겹 문자열도 연 자리의 겹 수를 들고 간다(`tomlMultiline{quote, depth}`). 배열 안에서 연 문자열이 닫히면 배열로 돌아가야 해서다. 둘 다 정수와 byte 라 `==` 로 견줄 수 있다(syntax.go 의 State).

## 결과

- `.toml` 이 강조된다. 코드펜스의 `toml` 도 그렇다
- 들여쓰기는 여러 줄 배열과 인라인 표의 괄호만 센다. 단위는 space 네 칸이다. 표 머리는 같은 줄에서 닫혀서 단계를 열지 않는다. 표 아래 키를 들여쓰지 않는 것이 Cargo.toml·pyproject.toml 의 흔한 꼴이다
- 뼈대(머리줄) 는 없다(`flatOutline`). 표 머리를 머리줄로 세우는 것은 강조와 따로 정한다(docs/tasks.md)
- **강조는 검사가 아니다.** 한글 맨이름 키(`이름 = 1`) 는 TOML 에서 틀린 것이지만 그냥 색 없이 지나간다
- lock 파일(`Cargo.lock`·`uv.lock`) 은 toml 형식인데 확장자가 달라서 아직 색이 없다(docs/tasks.md)

## 기각한 것

- **표 머리를 KindKey 로.** §1 에 적었다
- **키 자리를 문맥으로 세기.** 줄 앞, `{` 뒤, `,` 뒤를 가르고 그것이 배열 안인지 인라인 표 안인지를 다시 갈라야 한다. 뒤의 `=` 하나로 같은 답이 나온다
