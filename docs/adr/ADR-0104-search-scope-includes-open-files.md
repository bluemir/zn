# ADR-0104 검색 범위는 「뿌리 아래 + 열어 둔 파일」이다

- 상태: 채택
- 날짜: 2026-08-29
- 관련: ADR-0077(여러 파일 검색), ADR-0042(무시 규칙), ADR-0097(그 목록으로 치환한다), ADR-0021(같은 파일에 Buffer 는 하나)

## 맥락

`docs/tasks.md` 에 ADR-0077 의 후속으로 남아 있던 항목이다.

> 열려 있지만 훑는 목록에 없는 파일(무시된 파일을 tab 으로 연 경우) 도 검색에 넣는다. overlay 에는 있는데 `files` 를 돌아서 빠진다

ADR-0077 은 파일 목록을 팔레트와 같은 길로 얻기로 했다(`gitFiles`·`walkFiles`). `.gitignore` 가 공짜로 따라오고 검색만의 규칙을 새로 만들지 않는다는 것이 그 값이었다.

그런데 고치던 buffer 의 글을 얹는 자리가 `overlay[path]` 라서, **그 path 가 목록에 없으면 담아둔 글이 영영 쓰이지 않는다.** `.env` 나 `debug.log` 처럼 무시되는 파일을 tab 으로 열어 두고 `:grep` 을 치면, 화면에 그 글이 떠 있는데도 결과에 없다.

## 1. 열어 둔 파일은 목록에 없어도 넣는다

`gitFiles` 가 준 목록 뒤에 열린 buffer 의 경로를 붙인다(`appendOpenFiles`). 붙인 파일도 목록의 다른 파일과 똑같이 `grepFile` 을 지나므로, 고치던 것은 담아둔 글로 훑고 안 고친 것은 디스크를 읽는다. 새 길이 생기지 않는다.

**뒤에 붙인다.** 앞쪽은 저장소가 아는 차례라, 끼워 넣으면 같은 검색의 결과 차례가 열린 tab 에 따라 달라진다.

**두 번 넣지 않는다.** 이미 목록에 있는 파일을 또 훑으면 적중이 겹치고 파일 수도 두 번 센다.

무시 규칙 자체는 그대로다. 열지 않은 무시 파일은 여전히 검색에 들지 않는다. 바뀐 것은 「무시한다」가 아니라 「**보고 있는 것은 무시하지 않는다**」이다.

## 2. 뿌리 밖의 파일도 넣는다

처음에는 뿌리 안만 넣었다. 「검색 범위는 뿌리 전체」라는 말을 지키려던 것인데, 그러면 규칙이 둘이 된다. 열어 둔 파일은 넣지만 뿌리 밖이면 빼는 것이라, 사람이 보기에 왜 어떤 tab 은 걸리고 어떤 tab 은 안 걸리는지가 설명되지 않는다.

**「뿌리 아래 + 열어 둔 파일」한 줄로 둔다.** 뿌리 밖의 파일은 자가 `../other/x.go` 가 되는데, 재 보니 그 자가 끝까지 성립한다.

- 읽는 자리(`grepFile`) 와 쓰는 자리(`replaceFile`) 가 둘 다 `filepath.Join(root, path)` 를 지난다. `Join` 이 `..` 를 정리해서 제 파일이 된다.
- 적중에서 뛰는 것은 `openTab` 이고, 그 안의 `tabOf` 가 `samePath`(양쪽을 `Abs` 로 맞춘다) 로 견준다. 절대 경로로 열어 둔 그 tab 을 그대로 찾으므로 같은 파일이 두 tab 이 되지 않는다(ADR-0021).
- 목록에는 `../other/x.go:12` 로 선다. 어디 있는 파일인지가 그 자에 그대로 보인다.

## 3. 자를 만드는 자리는 하나다

`dirtyOverlay` 가 열린 파일 목록과 고치던 것의 글을 **한 번의 훑기로 같이 낸다.** `buf.path` 는 상대일 수도 절대일 수도 있어서(CLI 인자·트리·팔레트가 저마다 주는 대로 담긴다) 뿌리 기준으로 맞추는 셈이 필요한데, 그 셈이 두 자리에 있으면 목록에는 든 파일이 overlay 에서는 빠지는 자리가 생긴다. ADR-0077 이 「맞추지 않으면 overlay 가 조용히 빈다」로 이미 한 번 겪은 자리다.

## 밖에 둔 것

- **팔레트의 파일 목록.** 무시된 파일을 열어 두어도 팔레트에는 뜨지 않는다. 그쪽은 「열 파일을 고르는」 자리라 이미 열린 것을 낼 까닭이 없고, tab 을 오가는 길은 tabline 과 `gt` 가 따로 있다.
- **`:replace` 도 같이 넓어졌다.** 목록이 곧 바꿀 자리라 저절로 따라온다. 하나씩 `y` 로 확인하는 길이라(ADR-0097) 모르는 새 뿌리 밖 파일이 바뀌지는 않는다.
