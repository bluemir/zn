# knowledges

**알아 두면 다시 헤매지 않는 것**을 적는 자리다. 우리가 무엇을 골랐는지는 `../adr/`,
남의 코드에서 난 문제는 `../issues/`, 할 일은 `../tasks.md` 에 있다.

여기 적는 것은 **결정도 사건도 아닌 것** 이다 — 유니코드·터미널·Go 처럼 우리가 정하지
않았고 바뀌지도 않지만, 모르면 같은 자리에서 같은 실수를 하는 것들이다.

적을 때 지킬 것은 둘이다.

- **잰 값을 적는다.** 기억으로 적은 표는 다음 사람이 다시 재게 만든다. 잰 날과 판을
  같이 남긴다 — 라이브러리 판이 올라가면 표가 거짓이 된다
- **그것이 우리 코드 어디에 있는지 적는다.** 일반론만 있는 문서는 읽고 나서 무엇을
  고쳐야 할지 모른다

파일 이름은 `짧은-제목.md` 다. 번호를 붙이지 않는다 — 사건이 아니라 주제라서 시간순이
쓸모없고, 찾을 때 이름으로 찾는다.
