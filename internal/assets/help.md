# zn 도움말

vim 의 손버릇을 그대로 쓰는 터미널 편집기다. 이 글은 `:help` 로 열고 `q` 로 닫는다.

읽는 중에 `/` 로 찾는다. `n` 은 다음, `N` 은 이전이다. `j` `k` 로 한 행씩, `ctrl+d` `ctrl+u` 로 반쪽씩, `g` `G` 로 처음과 끝으로 간다. 판에서는 `g` 가 한 번이다. 편집 영역의 `gg` 와 갈린다.

## 시작하기

파일을 주고 연다. 여럿을 주면 tab 이 여럿이 된다.

```
zn 파일.txt
zn a.go b.go
zn
```

인자 없이 열면 빈 화면이다. `ctrl+p` 로 파일을 찾거나 `:e 경로` 로 연다.

**나가는 것은 `:q` 다.** 고친 것이 있으면 물어본다. `ctrl+c` 는 편집기 전체를 닫는 길이고 이것도 물어본다. 저장하고 나가는 것은 `:wq` 또는 `:x` 다.

키를 치다 길을 잃으면 `esc` 다. 어느 mode 에서든 normal 로 돌아온다.

## mode

지금 어느 mode 인지는 statusBar 왼쪽에 있다. 커서 모양도 갈린다. normal 은 네모(`block`), insert 는 막대(`bar`) 다.

| mode | 들어가는 법 | 나오는 법 |
|---|---|---|
| `NORMAL` | 처음 자리 | |
| `INSERT` | `i` `a` `o` `O` `c` | `esc` |
| `VISUAL` | `v` `V` | `esc` `v` |
| `COMMAND` | `:` | `esc` `enter` |
| `SEARCH` | `/` `?` | `esc` `enter` |
| `TREE` | `ctrl+w ctrl+w` | `esc` |
| `PALETTE` | `ctrl+p` | `esc` |
| `SYMBOL` | `:symbols` | `esc` |

`esc` 로 normal 에서 insert 로 돌아올 때 커서가 한 칸 왼쪽으로 간다. vim 과 같다.

## 움직이기

| 키 | 가는 곳 |
|---|---|
| `h` `j` `k` `l` | 왼쪽·아래·위·오른쪽. 화살표도 같다 |
| `w` `W` | 다음 낱말 첫 글자. 대문자는 공백으로만 끊는다 |
| `b` `B` | 앞 낱말 첫 글자 |
| `e` `E` | 낱말 마지막 글자 |
| `0` | 줄 맨 앞 |
| `^` | 줄의 첫 비공백 |
| `$` | 줄 끝 |
| `%` | 짝이 되는 괄호 |
| `gg` | 파일 첫 줄 |
| `G` | 파일 마지막 줄. 숫자를 붙이면 그 줄(`20G`) |
| `ctrl+d` `ctrl+u` | 반쪽씩 |
| `ctrl+f` `ctrl+b` | 한 쪽씩. `pgdown` `pgup` 도 같다 |
| `ctrl+o` | 뛰기 전 자리로 되돌아간다 |
| `tab` | 되돌아간 것을 다시 앞으로 |

**숫자를 앞에 붙이면 그만큼 되풀이한다.** `3j` 는 세 줄 아래, `2w` 는 낱말 둘이다.

커서는 가고 싶었던 칸을 기억한다. 긴 줄에서 `$` 로 간 뒤 `j` 를 누르면 다음 줄에서도 끝으로 간다.

## 고치기

| 키 | 하는 일 |
|---|---|
| `i` `a` | 커서 앞·뒤에 넣기 시작 |
| `o` `O` | 아래·위에 빈 줄을 열고 넣기 시작 |
| `x` | 글자 하나 지우기 |
| `d` + 이동 | 그 범위 지우기. `dw` `d$` `dgg` |
| `dd` | 줄 통째로 |
| `c` + 이동 | 그 범위를 지우고 넣기 시작. `cw` `cc` |
| `~` | 대소문자 뒤집기 |
| `J` | 다음 줄을 끌어올려 잇기 |
| `>` `<` + 이동 | 들여쓰기 밀기·당기기 |

**`d` 와 `c` 는 이동 키를 그대로 받는다.** 그래서 `dw` 가 멈추는 자리와 `w` 가 가는 자리가 같다.

낱말 안쪽을 잡는 길도 있다. `diw` 는 커서가 선 낱말을 지우고, `daw` 는 뒤의 공백까지 가져간다. `c` 도 같다(`ciw`).

읽기 전용 파일은 고쳐지지 않는다. 표준 라이브러리로 뛰어 들어간 자리가 그렇다. 고치려 하면 아래 줄에 알린다.

## 복사와 붙여넣기

| 키 | 하는 일 |
|---|---|
| `y` + 이동 | 그 범위 복사. `yw` `y$` |
| `yy` | 줄 통째로 |
| `p` | 커서 뒤에 붙이기 |
| `P` | 커서 앞에 붙이기 |

`y` 는 파일을 건드리지 않는다. 화면이 안 바뀌어서 담겼는지 볼 길이 없으므로 **아래 줄에 알린다.** 「3 줄 복사되었습니다」다.

줄 단위로 복사한 것은 줄로 끼워지고, 글자 단위로 복사한 것은 커서 자리에 끼워진다. `3p` 는 세 번 붙인다.

visual 에서 고른 범위도 `y` `d` `c` 를 그대로 받는다.

## register

담는 칸이 여럿이다. `"` 뒤에 이름을 대면 그 칸을 쓴다.

| 이름 | 무엇이 담기나 |
|---|---|
| `""` | 무명. 마지막으로 복사하거나 지운 것 |
| `"0` | 마지막으로 **복사**한 것. 지우기가 덮지 않는다 |
| `"1` ~ `"9` | 지운 것들. 지울 때마다 한 칸씩 밀린다 |
| `"a` ~ `"z` | 손으로 담는 칸 |

`"ayy` 로 `a` 에 담고 `"ap` 로 그것을 붙인다. **대문자를 쓰면 덮지 않고 뒤에 잇는다.** `"Ayy` 를 여러 번 하면 모인다.

숫자 칸은 손으로 담을 수 없다. 편집기가 채우는 자리라 다음 지우기가 밀어내면 넣어 둔 자리에 그것이 없다.

`:registers`(줄여서 `:reg`) 로 지금 무엇이 담겨 있는지 본다.

## 시스템 클립보드

**`"+` 를 이름으로 댄 것만 편집기 밖으로 나간다.**

```
"+yy      이 줄을 시스템 클립보드로
"+dd      잘라서 밖으로
"+p       밖에서 복사한 것을 붙이기
```

이름을 대지 않은 `y` `d` `x` `c` 는 편집기 안에만 담긴다. 한 글자 지운 `x` 가 다른 창에서 복사해 둔 것을 덮으면 되돌릴 길이 없어서다.

`"+` 로 보낸 것은 무명 칸에도 담긴다. 그래서 `"+yy` 뒤에 그냥 `p` 를 쳐도 같은 것이 붙는다.

**되었는지는 알 수 없다.** 터미널에 부탁하는 길(OSC 52) 이라 받았는지 답이 오지 않는다. 알림의 「(클립보드)」는 보냈다는 뜻이다. tmux 안에서는 `set-clipboard on` 이어야 담긴다.

읽기(`"+p`) 는 답하지 않는 터미널이 더 많다. 0.5 초 안에 답이 없으면 그렇다고 알린다. tmux 는 답하지 않는다.

`"*` 는 없다. `"+` 와 같은 것을 가리키는 이름이라 두지 않았다.

## 되돌리기

| 키 | 하는 일 |
|---|---|
| `u` | 되돌리기 |
| `ctrl+r` | 되돌린 것을 다시 |

**한 번 넣은 글자 덩이가 한 구간이다.** `i` 로 들어가 여러 글자를 치고 `esc` 로 나오면 `u` 한 번에 전부 사라진다. `3p` 도 한 번이다.

## 찾기와 바꾸기

| 키 | 하는 일 |
|---|---|
| `/` | 아래로 찾기 |
| `?` | 위로 찾기 |
| `n` `N` | 다음·이전 |
| `*` `#` | 커서가 선 낱말을 아래·위로 찾기 |

치는 대로 화면이 따라 움직인다. `enter` 로 그 자리에 두고 `esc` 로 원래 자리로 돌아온다. 찾은 것들은 색이 남고 `:noh` 로 지운다.

바꾸는 것은 `:s` 다.

```
:s/헌것/새것/          이 줄에서 첫 번째
:s/헌것/새것/g         이 줄에서 전부
:%s/헌것/새것/g        파일 전체
:'<,'>s/헌것/새것/g    visual 로 고른 범위
:10,20s/헌것/새것/g    줄 범위
:%s/헌것/새것/gc       하나씩 물어보며
```

여러 파일에 걸친 것은 `:grep` 으로 찾고 `:replace` 로 바꾼다. 팔레트의 `/` 도 프로젝트 검색이다.

## 파일과 tab

| 키·명령 | 하는 일 |
|---|---|
| `:e 경로` | 그 파일을 연다 |
| `:tabnew 경로` | 새 tab 으로 연다 |
| `gt` `gT` | 다음·이전 tab |
| `:w` | 저장 |
| `:w 경로` | 다른 이름으로 저장 |
| `:wq` `:x` | 저장하고 닫기 |
| `:q` | 닫기. 마지막 tab 이면 편집기가 끝난다 |
| `:qa` | 전부 닫기 |
| `:rename 새이름` | 지금 파일의 이름을 바꾼다 |

맨 윗줄(tabline) 에 열린 tab 이 늘어선다. 고친 tab 에는 표시가 붙는다. 마우스로 눌러 옮기거나 오른쪽 버튼으로 닫는다.

**밖에서 바뀐 파일은 알아서 따라온다.** 고친 것이 없으면 조용히 다시 읽고, 있으면 물어본다.

## 파일 트리

왼쪽에 기본으로 열려 있다. `:tree` 로 여닫는다.

| 키 | 하는 일 |
|---|---|
| `ctrl+w ctrl+w` | 트리와 편집 영역 사이를 오간다 |
| `j` `k` | 위아래 |
| `enter` | 폴더면 펼치고 파일이면 연다 |
| `gg` `G` | 처음과 끝 |
| `esc` | 편집 영역으로 |

구분선을 마우스로 끌면 폭이 바뀐다. 오른쪽 버튼을 누르면 그 자리에 메뉴가 뜬다.

파일 이름 오른쪽에 git 표시가 선다. `M` 은 고친 것, `?` 는 아직 추적하지 않는 것이다.

## 명령 팔레트

`ctrl+p` 로 연다. 맨 앞 글자가 갈래를 정한다.

| 맨 앞 | 무엇을 찾나 |
|---|---|
| (없음) | 파일 |
| `>` | 명령 |
| `/` | 프로젝트 안의 글 |
| `!` | 셸 명령 |
| `!&` | 백그라운드 셸 명령 |

글자가 순서만 맞으면 걸린다. `ced` 로 `core/edit.go` 가 걸린다. 가운데의 `/` 는 그냥 글자라 `core/edit` 은 파일 찾기다.

## 마우스

- **왼쪽 끌기**: 범위 고르기. visual 이 열린다
- **가운데 굴리기**: 화면 옮기기
- **tabline 왼쪽 끌기**: tab 옮기기
- **tabline 오른쪽**: tab 닫기
- **트리 오른쪽**: 메뉴
- **구분선 끌기**: 트리 폭
- **아래 줄의 tip**: 눌러서 tip 목록으로

터미널 제 드래그(글자를 긁어 복사하는 것) 를 쓰려면 `shift` 를 누른 채 끈다.

## git

저장소 안이면 statusBar 오른쪽에 가지 이름과 고친 파일 수가 뜬다.

| 키·명령 | 하는 일 |
|---|---|
| `]c` `[c` | 다음·이전 고친 자리 |
| `:graph` | 커밋 기록 |
| `:diff` | 지금 파일과 HEAD 를 견준다 |
| `:diff A B` | 둘을 견준다 |

줄번호 왼쪽에 표시가 선다. `+` 는 넣은 줄, `~` 는 고친 줄, `_` 는 그 아래가 지워진 자리다.

## 언어 서버

Go 파일에서 gopls 가 붙는다. 없으면 조용히 넘어간다.

| 키·명령 | 하는 일 |
|---|---|
| `\gd` | 정의로 뛴다 |
| `\gr` | 쓰는 곳 목록 |
| `\rn` | 이름 바꾸기 |
| `]d` `[d` | 다음·이전 진단 |
| `ctrl+o` | 뛰기 전으로 |

`\` 가 leader 키다.

맨 왼쪽 칸에 진단 표시가 선다. `✖` 는 오류, `⚠` 는 경고다. 그 줄에 커서를 두면 아래 줄에 문구가 붙는다.

insert 에서 치는 동안 후보가 뜬다. `tab` 으로 고르고 `enter` 로 넣는다.

## 판 목록

화면을 통째로 쓰거나 아래에 펼쳐지는 화면들이다. 대개 `j` `k` 로 움직이고 `q` 나 `esc` 로 닫는다.

| 명령 | 무엇을 보나 |
|---|---|
| `:help` | 이 글 |
| `:tips` | 짧은 도움말 문장 모음. `/` 로 거른다 |
| `:registers` | 담긴 것들 |
| `:messages` | 지나간 알림 |
| `:jobs` | 백그라운드 작업 |
| `:history` | 명령줄에 쳤던 것 |
| `:jumps` | 뛰어다닌 자리 |
| `:symbols` | 특수문자 넣기 |
| `:graph` | 커밋 기록 |
| `:diff` | 견주기 |
| `:version` | 판 번호 |

## 셸과 백그라운드 작업

```
:!명령        터미널을 넘겨준다. 끝나면 돌아온다
:!&명령       백그라운드로 돌린다
```

백그라운드로 돌린 것은 statusBar 에 진행이 뜨고 `:jobs` 로 본다. 끝나면 알린다.

## 화면 보기

**들여쓰기와 줄 끝의 공백에 흐린 표시가 붙는다.** `»` 는 tab, `⋅` 는 space 다. 줄 가운데의 것은 표시하지 않는다.

tab 폭은 파일마다 다르다. `.editorconfig` 의 `tab_width` 를 따르고 적힌 것이 없으면 4 다.

줄번호는 절대와 상대를 같이 보여준다. 상대 번호가 있으면 `5j` 같은 것을 셀 필요가 없다.

긴 줄은 접어서 보여준다. 접힌 자리는 줄번호 칸이 비어 있다.

**밖으로 글을 낼 때는 `\c`(평문출력) 다.** 화면 장식을 뺀 글을 터미널에 그대로 찍어서 마우스로 긁을 수 있다. visual 에서 `\c` 는 고른 범위만이다. 다만 터미널에 따라 긁을 때 tab 이 공백이 되므로, 그럴 때는 `"+y` 쪽이 온전하다.

## 명령 전체

`:` 로 연다. 위아래 화살표로 지난 것을 꺼내고 `tab` 으로 채운다.

| 명령 | 하는 일 |
|---|---|
| `:w` `:wq` `:x` `:q` `:qa` | 저장과 닫기 |
| `:e 경로` `:tabnew 경로` | 열기 |
| `:rename 이름` | 이름 바꾸기 |
| `:d` `:y` | 줄 범위를 지우거나 복사 |
| `:s/A/B/` | 바꾸기 |
| `:grep 글` | 여러 파일에서 찾기 |
| `:replace A B` | 여러 파일에서 바꾸기 |
| `:noh` | 찾은 표시 지우기 |
| `:!명령` `:!&명령` | 셸 |
| `:cat` | 평문으로 내보내기 |
| `:tree` | 트리 여닫기 |
| `:diff` `:graph` | git |
| `:help` `:tips` `:registers` `:messages` `:jobs` `:history` `:jumps` `:symbols` `:version` | 판 열기 |

**줄 범위를 앞에 붙인다.** `:10,20d` 는 그 줄들을 지우고 `:%y` 는 파일 전체를 복사한다. `:'<,'>` 는 visual 로 고른 범위이고, visual 에서 `:` 를 누르면 이미 채워져 있다.

## 한글로 칠 때

입력기가 한글인 채로 normal mode 에 오면 **자모를 두벌식 자리의 영문 키로 되돌려 받는다.** `ㅁ` 은 `a` 이고 `ㅓ` 는 `j` 다. 그래서 한글 상태로 `ㅈㅈ` 를 쳐도 `ww` 가 아니라 제 일을 한다.

다만 입력기가 아예 내보내지 않는 키가 있다. `G` `B` `V` `U` 는 한글 상태에서 칠 수 없으므로 입력기를 영문으로 바꿔야 한다.
